StudyFinder

Website Planning Document

Prepared by Armindo Armando Mazivila

1. Site Name

StudyFinder

StudyFinder is a name that combines two simple words: "Study" and "Finder". The name communicates the main purpose of the platform: helping students find educational resources and information more easily.

The name was selected because it is simple, memorable, and understandable to students from different countries.

Proposed domain: studyfinder.org
Note: Domain availability has not yet been verified.

2. Site Purpose

StudyFinder will be an educational platform designed to help students around the world discover free learning resources on different subjects and topics.

Visitors will be able to search for educational topics, explore useful learning websites, and access reliable external resources.

The platform will initially provide content in English. A language selector will allow users to choose other languages. Where possible, translated explanations will appear alongside the original learning resources.

The main goal is to make educational information easier to discover and understand, especially for students who face language barriers or have limited access to learning materials.

Future development may include additional languages, more learning categories, and advertising to support the platform's operation.

3. Target Audience and Scenarios

Target Audience

StudyFinder is intended for students, independent learners, and anyone interested in improving their knowledge through online educational resources.

Visitor Scenarios

  1. Where can I find free online resources to learn programming as a beginner?
  2. Can I find educational resources explained in Portuguese instead of English?
  3. Which websites provide reliable information about mathematics, science, and technology?
  4. How can I discover learning materials without spending money?

4. Color Scheme

StudyFinder will use a clean and professional color scheme that communicates trust, learning, and clarity.

Selected Colors

Primary: #17324D
Used for the header, footer, and main headings. This dark blue represents trust and professionalism.

Secondary: #0F766E
Used for section accents and highlighted information. It represents growth and learning.

Accent: #F4B942
Used for decorative details and important highlights.

Background: #F5F7FA
Used as the main page background to keep the design clean and comfortable to read.

Text: #263238
Used for paragraphs and general content.

5. Typography

Poppins

Poppins will be used for headings, including the main website title and section headings. Its appearance is modern and clear.

Roboto

Roboto will be used for paragraphs, descriptions, navigation text, and general website content because it is easy to read on desktop and mobile screens.

The website will use these two fonts consistently to create a simple and readable experience.

6. Wireframes

The StudyFinder homepage will have a responsive layout that works on mobile phones, tablets, and desktop computers.

Small Viewport – Mobile

The mobile homepage will have a vertical layout. The header will contain the StudyFinder logo and a menu button. Below it, visitors will see a welcome message, a search area, learning categories, and recommended educational resources.

Large Viewport – Desktop

The desktop homepage will use a wider layout. The navigation links will appear horizontally. The search area will be prominent, and learning categories and recommended resources may appear in columns.
